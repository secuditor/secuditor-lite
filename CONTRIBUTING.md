# Contributing to Secuditor Lite

Thank you for your interest in contributing to **Secuditor Lite**, Contributions such as code, documentation, testing, ideas, and feedback are welcome.

---

## When Using AI Copilot

Using GitHub Copilot in pull requests may cause Copilot to appear in repository activity or suggestion history.

For clear attribution and meaningful contribution tracking:

- Use Copilot as an assistant, not the primary author of changes
- Ensure meaningful changes are reviewed and committed by humans
- Prefer manual commits for core logic and important updates

---

## Code of Conduct & Ethics

By contributing, you agree to uphold the following principles:

* All contributions must support **legal, ethical, and authorized diagnostics** only
* Being respectful of differing opinions, viewpoints, experiences, and Feedback
* The maintainer reserves the right to reject contributions that conflict with these principles

---

## Ways to Contribute

You can help in the following ways:

### Code Contributions

* Bug fixes
* Performance improvements
* Cross-platform compatibility enhancements
* Refactoring for readability and maintainability
* Adding safe, ethical diagnostic features

### Documentation

* Improve README clarity
* Add usage examples
* Fix typos or grammar
* Improve comments and docstrings

### Testing

* Test on different Windows versions
* Report bugs, regressions, or edge cases
* Validate accuracy, stability, and performance

### Ideas & Feedback

* Feature requests (ethical only)
* UI improvements for performance and output
* Suggestions for better logging or reporting

---

## Development Guidelines

To keep the project clean and consistent, please follow these rules:

* Python version: Python 3.10 or later
* Avoid OS-specific hacks unless clearly isolated
* Write clear, readable, and well-commented code
* Platform compatibility: Maintain compatibility with supported Windows

---

## Security-Focused Contributions

This tool is designed for **defensive diagnostics**, not exploitation.

✅ Acceptable:

* Device discovery improvements
* Scan accuracy enhancements
* Safer port detection logic
* Better error handling and timeouts

❌ Not acceptable:

* Exploit payloads
* Credential harvesting
* Evasion techniques
* Attack methods

---

## How to Submit a Contribution

1. Fork the repository
2. Make your changes
3. Test on at least one supported OS
4. Commit with a clear message
5. Open a **Pull Request** with:
   * What you changed
   * Why it’s useful
   * Any relevant notes or limitations

---

## Reporting Bugs

When reporting a bug, please include:

* OS and version
* Python version
* Command used
* Expected vs actual behavior
* Error output or logs (if available)

Clear reports help fix issues faster 👍
