# Privacy Policy

**Secuditor Lite** is a diagnostic security tool that runs locally on your device.
It does not intentionally collect or store personal data or system information without the user's explicit action or consent. 
The application is designed to minimize external communication and keep security analysis within the local environment.

During security audits, Secuditor Lite may access locally available technical information required to perform the requested checks. This may include system configuration, running processes, installed applications, network settings, security services, certificates, and other security-related information. This information is processed locally as part of the requested analysis.

All analyses, reports, logs and cache generated by the application are stored locally on your device, in the same folder where the software resides or in other local application folders.

The application may periodically communicate with our secure servers to:
- Verify the availability of software updates.
- Support application version and integrity checks.
- Retrieve updated security resources, including detection methods and application reputation databases.

These connections transmit only non-personal, technical data (e.g., version identifiers or checksum values).

When Secuditor Lite communicates with our servers, our systems may temporarily log the public IP address associated with your internet connection.

Optional third-party online checks (such as public IP lookups, NAT checks, TLS/SSL security checks, or external connection analysis) are performed only when initiated by you.
These online checks may involve connecting to third-party servers, which may receive your public IP address and other technical information as part of the internet connection.
